System Requirements

Ensure your system meets the requirements to run MEDSYS efficiently

Minimum Requirements

  • Operating System: Windows 10 / macOS / Linux
  • Processor: Intel i3 or equivalent
  • RAM: 4 GB
  • Storage: 500 MB free space
  • Internet: Stable connection

Recommended Requirements

  • Operating System: Windows 11 / Latest macOS
  • Processor: Intel i5 or higher
  • RAM: 8 GB or more
  • Storage: SSD preferred
  • High-speed internet connection

Supported Browsers

  • Google Chrome (latest)
  • Microsoft Edge
  • Mozilla Firefox
  • Safari (macOS)

Notes

For best performance, always keep your browser updated and avoid using outdated systems. MEDSYS may not function properly on unsupported devices.
